Pulau Institute is a Southeast Asian research and arts institution exploring the internet, pop culture, critical infrastructure, and collective memory.

This project stewards towards a living project space, a research lab, and an art collective; studying and shaping the internet(s) we inherit, inhabit, and imagine.
